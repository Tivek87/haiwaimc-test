=====================================================================
  HAWAII STRAND GENERATOR  -  Minecraft NeoForge 1.21.1 (datapack)
=====================================================================

WAT DOET HET?
  Genereert een Hawaii-strand van 1 t/m 8 chunks (16x16 t/m 128x128
  blokken), gecentreerd op de plek waar je staat:

    WEST  [ zee + koraal ] [ strand + palmen + TIKI BAR ] [ jungle ] [ heuvels ]  OOST

  - Zee: diep -> ondiep, warm koraal, zeegras, kelp, tropische vissen
  - Strand: palmbomen (recht + schuin) met kokosnoten, parasols, schildpadden
  - Tiki bar: bamboe palen, rieten dak, toonbank, barkrukken,
    tiki fakkels, naambord, papegaai, en barman "Kai" (villager)
    die Pina Colada, Blue Hawaii, Mai Tai en meloen verkoopt
    (en cacaobonen inkoopt)
  - Jungle + heuvels op de achtergrond: jungle bomen, bamboe,
    struiken, meloenen, bloemen, papegaaien, ocelots

INSTALLEREN
  1. Download de nieuwste "hawaii_beach-vX.Y.Z.zip" van de Releases-pagina:
     https://github.com/tivek87/haiwaimc-test/releases
     (of kopieer de map "hawaii_beach")
  2. Zet hem in:   .minecraft/saves/<jouw wereld>/datapacks/
     (server: world/datapacks/)
  3. In de game:   /reload
  4. Check:        /datapack list   -> "file/hawaii_beach" moet erbij staan

GEBRUIK (chat)
  /function hawaii:beach          -> 4 x 4 chunks (standaard)
  /function hawaii:beach_1        -> 1 x 1 chunk   ( 16 x  16 blokken)
  /function hawaii:beach_2        -> 2 x 2 chunks  ( 32 x  32)
  ...
  /function hawaii:beach_8        -> 8 x 8 chunks  (128 x 128)

  Of met een getal:
  /function hawaii:generate {chunks:4}     (1 t/m 8)

  LET OP: "/function hawaii:beach {chunks:8}" werkt NIET voor de
  grootte (dan krijg je gewoon 4x4). Gebruik beach_8 of generate.

COMMAND BLOCK
  Impulse command block, "Needs Redstone", en zet erin:

    execute as @p at @p run function hawaii:beach_4

  (of: execute as @p at @p run function hawaii:generate {chunks:4})

  -> bouwt het strand rond de dichtstbijzijnde speler.
  (Zonder "execute as @p at @p" wordt het rond het command block
   zelf gebouwd en wordt het command block weggehaald.)

HOE LANG DUURT HET?
  Er komt een voortgangsbalk bovenin je scherm met een percentage.
     1 x 1 chunk   ~1,5 seconde
     4 x 4 chunks  ~2 seconden
     8 x 8 chunks  ~3 seconden
  (plus een paar tellen als de chunks nog geladen moeten worden)
  Het strand wordt gebouwd waar jij stond toen je het command gaf.
  Na afloop word je voor de tiki bar gezet.

TIPS
  - Je hebt cheats / OP (level 2) nodig.
  - Bij 8 chunks moet je render distance minimaal 6 zijn, anders
    zijn niet alle chunks geladen en wordt het gebied half gebouwd.
  - Ga op ongeveer zeeniveau staan; het gebied wordt van 8 blokken
    onder je voeten tot 40 blokken boven je hoofd vervangen.
  - Opnieuw uitvoeren mag: de oude barman en papegaai worden eerst
    verwijderd zodat je er geen dubbele krijgt.

WIJZIGINGEN
  Zie docs/CHANGELOG.md (datum, tijd en wat er veranderd is per versie).

BESTANDEN
  hawaii_beach/data/hawaii/function/
    beach.mcfunction            <- snelle start, 4x4 chunks
    beach_1 .. beach_8          <- vaste groottes
    generate.mcfunction         <- startpunt met {chunks:N}
    internal/calc.mcfunction    berekent de zones
    internal/start + tick       bouwt stap voor stap met voortgangsbalk
    internal/s_*.mcfunction     de bouwstappen (lucht, grond, zee, land, decoratie)
    internal/tiki_bar.mcfunction   de tiki bar + barman
    grid/*.mcfunction           verdeelt decoratie over het gebied
    deco/*.mcfunction           palmen, parasols, zee, jungle
